# approval-cards

Renderer for Claude approval cards. Load from jsDelivr, then call `renderCard(element, config)`.

```html
<div id="ac"></div>
<script src="https://cdn.jsdelivr.net/gh/casey-jones-australia/approval-cards@2.4.0/card.js"></script>
<script>renderCard(document.getElementById('ac'), { title: 'Example', rows: [] })</script>
```

The master copy lives in the approval-cards skill. Edit it there, then release a new tag here.
